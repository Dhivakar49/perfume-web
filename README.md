# 🛍️ Perfume Palace - E-Commerce Platform

A professional PHP e-commerce platform for luxury perfume sales.

## 🚀 Quick Start

### Start the Server
```bash
php -S localhost:8000
```
Or double-click: `admin/run-server.bat`

### Access the Site
- **Homepage**: http://localhost:8000
- **Admin Panel**: http://localhost:8000/admin/

## 🔧 Setup

1. **Install Requirements**
   - PHP 7.4+
   - MySQL 5.7+

2. **Start MySQL**
   - XAMPP users: Start MySQL from XAMPP Control Panel

3. **Run Setup**
   - Visit: http://localhost:8000/admin/setup-products.php

4. **Start Shopping!**
   - Visit: http://localhost:8000
